# PS4 GoldHEN Manager v1.0.0

Primera versión pública gratuita y open source.

## Incluye

- Detección automática de PS4 en la red local.
- Gestor FTP para GoldHEN.
- Transferencias PC ↔ PS4 y subida a `/data/pkg`.
- Instalador PKG remoto mediante RPI.
- GoldHEN Payload Server.
- Klog.
- Integración con ps4debug-NG.
- Biblioteca de juegos.
- Información de PS4 y estado de servicios.
- Cheats & Mods para uso local/offline.
- Aplicación Windows compilada sin consola de Python.

Las secciones experimentales Online, Trofeos y Temas quedan fuera de esta primera versión pública mientras siguen en desarrollo.

> Usa únicamente homebrew, payloads y PKG que tengas derecho a utilizar.
