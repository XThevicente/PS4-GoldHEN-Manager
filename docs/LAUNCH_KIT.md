# PS4 GoldHEN Manager — Public launch copy

## Reddit

**Title**

[Release] PS4 GoldHEN Manager v1.0.0 — FTP, PKG installer, payloads, ps4debug & cheats from one Windows app

**Post**

Hi! I’ve released the first public version of **PS4 GoldHEN Manager**, a free and open-source Windows companion app for PS4 consoles running GoldHEN.

The goal is simple: put the most useful PC-side GoldHEN tools in one clean interface instead of juggling several separate utilities.

### Current features

- Automatic PS4 discovery on the local network
- GoldHEN FTP file manager
- PC ↔ PS4 transfers
- Upload PKG files to `/data/pkg`
- Remote Package Installer support
- GoldHEN Payload Server support
- Klog viewer
- ps4debug-NG integration
- Installed-game library / PS4 information
- Cheats & Mods support for compatible GoldHEN definitions (local/offline use)

The project is **100% free and open source**. No accounts, licenses or paid tier.

GitHub / download:
https://github.com/XThevicente/PS4-GoldHEN-Manager

This is v1.0.0, so feedback and bug reports are very welcome. If you test it, please include your PS4 firmware, GoldHEN version and what feature you were using when reporting an issue.

Experimental Online, Themes and Trophies sections are intentionally not included in this first public build while they are being reworked.

Use only homebrew / PKG content you are authorized to use.
